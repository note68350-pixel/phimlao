# 🇱🇦 ພີມລາວ (PhimLao) - ເວັບເກມຝຶກພິມສັບພາສາລາວ

ເວັບເກມຝຶກພິມສັບພາສາລາວແທ້ 100% (ບໍ່ມີສັບໄທປະສົມ) ພັດທະນາຂຶ້ນເພື່ອຊ່ວຍໃຫ້ຄົນລາວ, ນັກຮຽນ, ນັກສຶກສາ ແລະ ພະນັກງານ ສາມາດຝຶກທັກສະການພິມແປ້ນພິມພາສາລາວໄດ້ຢ່າງຄ່ອງແຄ້ວ, ຖືກຕ້ອງ ແລະ ວ່ອງໄວ.

---

## ✨ ຈຸດເດັ່ນຂອງເກມ (Key Features)

1. **ຄັງຄຳສັບພາສາລາວແທ້ 100%:**
   - ຮວບຮວມຄຳສັບລາວແທ້ຫຼາຍກວ່າ **238 ຄຳສັບ ແລະ ປະໂຫຍກ**.
   - ກວດສອບອັກຂະຣະວິທະຍາ Unicode ລາວ (U+0EB0 – U+0EDF) ບໍ່ມີຄຳສັບໄທ, ຄຳແປງໄທ ຫຼື ຕົວສະກົດໄທປົນເປືອຍ.
   - ແບ່ງເປັນ **3 ລະດັບຄວາມຍາກ**:
     - **ງ່າຍ (Easy):** ຄຳສັບໂດດ 1-2 ພະຍາງ (ແມວ, ໝາ, ປາ, ກິນ, ບ້ານ, ນໍ້າ...)
     - **ກາງ (Medium):** ຄຳສັບປະສົມ 2-3 ພະຍາງ (ໂຮງຮຽນ, ນັກຮຽນ, ຄວາມຮັກ, ວັດທະນະທຳ, ແຂວງຕ່າງໆ...)
     - **ຍາກ (Hard):** ສຸພາສິດ, ຄຳພັງເພີຍ, ກາບກອນ ແລະ ປະໂຫຍກຍາວ (ຄວາມພະຍາຍາມຢູ່ໃສ ຄວາມສຳເລັດຢູ່ຫັ້ນ...)

2. **3 ໂໝດການຫຼິ້ນຫຼັກ (3 Game Modes):**
   - **⚡ ໂໝດທົດສອບຄວາມໄວ (Speed Test):** ຮູບແບບ Monkeytype ວັດຜົນ WPM (ຄຳ/ນາທີ), CPM (ຕົວອັກສອນ/ນາທີ) ແລະ ຄວາມຖືກຕ້ອງ (%) ພ້ອມຕົວນັບເວລາ (15s, 30s, 60s) ຫຼື ກຳນົດຈຳນວນຄຳ (10, 25 ຄຳ).
   - **👾 ໂໝດເກມຝົນຄຳສັບ (Falling Words Arcade):** ຮູບແບບ ZType ຄຳສັບລາວຕົກລົງມາຈາກຟ້າ, ພິມຍິງທຳລາຍ, ລະບົບຄອມໂບ, ເກັບຄະແນນ ແລະ ລະດັບຄວາມໄວທີ່ເພີ່ມຂຶ້ນ.
   - **⌨️ ໂໝດຝຶກແປ້ນພິມ & ນິ້ວມື (Keyboard & Finger Trainer):** ມີໄຮໄລ້ປຸ່ມກົດເທິງແປ້ນພິມສະເໝືອນ (Virtual Keyboard) ແລະ ແນະນຳຕຳແໜ່ງນິ້ວມືທີ່ຖືກຕ້ອງ (ນິ້ວກ້ອຍ, ນິ້ວນາງ, ນິ້ວກາງ, ນິ້ວຊີ້, ນິ້ວໂປ້).

3. **ຮອງຮັບທັງຄອມພິວເຕີ ແລະ ມືຖື (Responsive & Mobile-Friendly):**
   - **Computer / PC:** ຮອງຮັບແປ້ນພິມຈິງ, ປຸ່ມລັດ Tab ເພື່ອເລີ່ມໃໝ່, ແລະ ລະບົບ **Auto-Lao Key Translation** (ກົດປຸ່ມ QWERTY ແລ້ວແປງເປັນພາສາລາວອັດຕະໂນມັດ ສຳລັບຄອມທີ່ບໍ່ມີຄີບອດລາວຕິດຕັ້ງ).
   - **Mobile / Smartphone / Tablet:** ຮອງຮັບທັງແປ້ນພິມມືຖື (Gboard Lao, iOS Lao Keyboard) ຜ່ານ Touch Auto-Focus ແລະ ສາມາດກົດປຸ່ມເທິງແປ້ນພິມສະເໝືອນໄດ້ໂດຍກົງ.

4. **ລະບົບສຽງ Web Audio API Synthesizer:**
   - ສຽງກົດປຸ່ມ Switch, ສຽງພິມຖືກ, ສຽງພິມຜິດ, ສຽງຄອມໂບ ແລະ ສຽງຈົບເກມ ໂດຍບໍ່ຕ້ອງດາວໂຫຼດໄຟລ໌ສຽງຈາກພາຍນອກ.

## 🚀 ວິທີການເປີດຫຼິ້ນ (How to Run)

### ວິທີທີ 1: ເປີດຫຼິ້ນທັນທີ (ບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງເພີ່ມ)
- ພຽງແຕ່ດັບເບິລຄລິກເປີດໄຟລ໌ `index.html` ໃນໂຟລເດີນີ້ ຜ່ານ Browser ໃດກໍໄດ້ (Chrome, Edge, Firefox, Safari).

### ວິທີທີ 2: ເປີດຜ່ານ Local Web Server (ເພື່ອທົດລອງຫຼິ້ນເທິງມືຖືໃນວົງ Wi-Fi ດຽວກັນ)
ເປີດ PowerShell ຫຼື Terminal ໃນໂຟລເດີນີ້ ແລ້ວພິມ:
```bash
# ໃຊ້ Python
python -m http.server 3000

# ຫຼື ໃຊ້ Node.js
npx serve .
```
ຫຼັງຈາກນັ້ນ:
- ເທິງຄອມພິວເຕີ: ເປີດ `http://localhost:3000`
- ເທິງມືຖື: ເປີດ `http://[IP_ຂອງຄອມພິວເຕີ]:3000` (ຕົວຢ່າງ: `http://192.168.1.15:3000`)

## 🌐 ວິທີນຳຂຶ້ນອອນລາຍໃຫ້ທຸກຄົນທີ່ມີລິ້ງຫຼິ້ນໄດ້ຟຣີ (Deploy to Free Web Hosting)

ທ່ານສາມາດນຳເວັບເກມນີ້ຂຶ້ນອອນລາຍໄດ້ງ່າຍໆພາຍໃນ 1 ນາທີ:

1. **GitHub Pages (ຟຣີ 100%):**
   - ສ້າງ GitHub Repository ແລ້ວອັບໂຫຼດໄຟລ໌ທັງໝົດໃນໂຟລເດີນີ້ຂຶ້ນໄປ.
   - ໄປທີ່ **Settings** > **Pages** > ເລືອກ Branch `main` ແລ້ວກົດ **Save**.
   - ຈະໄດ້ລິ້ງເຊັ່ນ: `https://your-username.github.io/phimlao/`

2. **Vercel / Netlify (ຟຣີ 100%):**
   - ພຽງແຕ່ Drag & Drop (ລາກໂຟລເດີນີ້ໄປວາງ) ໃນໜ້າເວັບ [vercel.com](https://vercel.com) ຫຼື [netlify.com](https://netlify.com)
   - ທ່ານຈະໄດ້ລິ້ງອອນລາຍທັນທີ ເຊັ່ນ: `https://phimlao.vercel.app` ໃຫ້ທຸກຄົນຫຼິ້ນໄດ້ທົ່ວໂລກ!
